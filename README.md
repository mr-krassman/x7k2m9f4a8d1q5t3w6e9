# crypto_research

Данный проект представляет собой анализ и выявление статистически значимых аномалий и закономерностей на криптовалютном рынке. В фокусе исследования — поиск повторяющихся паттернов, которые могут служить основой для торговой стратегии.

## Цель проекта

Основная цель — обнаружить статистически значимые отклонения в поведении цены, которые:

- **могут быть использованы для прогнозирования краткосрочных движений (p < 0.05 после поправки Бонферрони);**
- **воспроизводятся на ≥ 60% временны́х участков;**
- **встречаются на ≥ 60% пар.**

## Методология

Для исследований были скачаны с биржи Bybit 49 пар с высоким месячным оборотом.  
Часть пар (24) имеют данные с начала 2022 года, остальные начинают историю позже — в период с 2022 по начало 2023 года.

Значимость найденных закономерностей проверяется в двух режимах:

### 1. Универсальность среди пар (cross‑asset)

- **Train**: 24 пары, период 2022-01-01 – 2026-05-31 (ранние данные)
- **Val**: 25 пар, период 2023-01-01 – 2026-05-31 (более новые пары, не пересекаются с train)

### 2. Устойчивость во времени (out‑of‑time)

- **Train**: 49 пар, период 2022-01-01 – 2024-04-01
- **Val**: 49 пар, период 2024-04-01 – 2026-05-31  
  (одни и те же пары, два непересекающихся временных окна)

### Ключевые выводы

По критериям проекта — значимость на train (Bonferroni), подтверждение на **≥ 60% пар** и **≥ 60% временных окон** — устойчивы **три дня недели (UTC)**:

| День   | Направление | Смысл для стратегии                                                                                                          |
| ------ | ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Чт** | минус       | Систематическое intraday-падение: эффект подтверждён на 88% val-пар (кросс-актив) и 73% пар во втором периоде (out-of-time). |
| **Пт** | плюс        | Положительный open→close: подтверждение 92% / 80% — эффект и универсален, и стабилен во времени.                             |
| **Сб** | плюс        | Аналогично пятнице (92% / 69%); наименьшая волатильность среди значимых дней.                                                |

**Почему остальные дни отсеяны** (не «нет эффекта», а не прошли оба фильтра):

- **Вт, Ср, Вс** — статистически заметны на одной когорте пар, но **не держатся во втором временном окне** (знак эффекта ослабевает или меняется; подтверждение 31–57%).
- **Пн** — на грани по парам (59% val), по времени не подтверждён.

**Итог:** торгово релевантный календарный паттерн — **short в четверг, long в пятницу и субботу** (open→close, gross). Детальные таблицы (сила close, High/Low) описывают _форму_ эффекта: у субботы — смещение к слабому росту при подавленных сильных падениях; у пятницы — повышенная доля положительных и сильных close; у четверга — преобладание отрицательных close.
