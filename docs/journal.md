# Journal — crypto_research

Данный проект представляет собой анализ и выявление статистически значимых аномалий и закономерностей на криптовалютном рынке. В фокусе исследования — поиск повторяющихся паттернов, которые могут служить основой для торговых сигналов.

## Цель проекта

Основная цель — обнаружить статистически значимые отклонения в поведении цены, которые:

- **могут быть использованы для прогнозирования краткосрочных движений**
- **воспроизводятся из года в год**
- **встречаются на 2+ пар**
